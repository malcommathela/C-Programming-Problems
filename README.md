## 🚀 How to Run

### Using GCC

Compile any C program:

```bash
gcc filename.c -o filename
```

Run it:

```bash
./filename
```

### Example

```bash
gcc BubbleSort.c -o BubbleSort
./BubbleSort
```

On Windows:

```powershell
gcc BubbleSort.c -o BubbleSort.exe
.\BubbleSort.exe
```
